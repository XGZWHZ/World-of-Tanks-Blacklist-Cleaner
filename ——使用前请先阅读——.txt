========================================
 坦克世界 WoT黑名单清理工具包 V3.0 正式版
========================================

【如何使用？按顺序做，一共五步】

  1_环境检查.bat              第一次用先跑这个（没有 Python 会自动安装）
  2_安装MOD.bat               把 MOD 装进当前客户端版本目录
  3_在线查询黑名单最后战斗时间.bat   去官网查每个人的最后战斗时间
  4_查看黑名单.bat            生成 黑名单列表.xlsx
  5_清理黑名单中长期不在线玩家.bat   筛选 + 批量删除 + 出报告


【该小工具里面有什么】

  python-3.15.2-amd64.exe      Python 安装包（第 1 步会自动调用）
  mod\blacklist_exporter_2.0.2.wotmod   游戏内 MOD
  tools\           脚本源码
  结果文件都生成在本目录（和 .bat 同级）


【第 1 步：环境检查】

  双击 1_环境检查.bat。
  - 没装 Python：自动调用根目录的 python-*-amd64.exe 静默安装；
  - 已经装了：直接打印 Python 版本、依赖、游戏目录、MOD 是否就位。
  安装完成后如果窗口还提示找不到，关掉重开一次即可。


【第 2 步：安装 MOD】

  双击 2_安装MOD.bat。它会：
  - 扫描各盘，找到含 WorldOfTanks.exe 的安装目录；
  - 读 version.xml（读不到就读 exe 版本），匹配 mods\<版本>\；
  - 把 wotmod 复制进去。
  然后启动游戏，进车库等 20 秒，MOD 会写出 blacklist_export.json。


【第 3 步：在线查询最后战斗时间】

  双击 3_在线查询黑名单最后战斗时间.bat。
  首次会让你选区服：1 国服  2 美服  3 欧服  4 亚服（记住后不再问）。
  它会逐个访问官网玩家页，补出最后战斗时间/注册时间，并输出：
    黑名单最后战斗时间表.xlsx
    blacklist_enriched.json

  查询方式采用异步 IO + 全局限速 + 动态调速 + 随机抖动；成功慢慢提速、失败自动降速并冷却
  避免被限速后查询失败；中断重跑会接着补路黑名单。默认 1.5 请求/秒起，640 人约 7~10 分钟。
  窗口里会实时显示：[128/632 20%] 当前: 某昵称 剩余 504 | 速率 1.7/s | 已用 13分 | 预计 51分

  *如果进度条无响应，可尝试按回车/Esc 或 关闭 QuickEdit 模式：用户右键标题栏 → 属性 → 取消“快速编辑模式”


【第 4 步：查看黑名单】

  双击 4_查看黑名单.bat，生成 黑名单列表.xlsx 并自动打开。
  列：用户ID、昵称、标签、在线、最后战斗时间、距今天数、总场次、状态。


【第 5 步：清理长期不在线玩家】

  双击 5_清理黑名单中长期不在线玩家.bat，菜单内有三项：
    1 预览（只列不删）
    2 部署删除（写名单 + 任务开关到游戏根目录）
    3 生成删除报告 Excel
  部署后启动游戏进车库，10 秒倒计时后自动进行删除任务（约 2 秒/人）。
  删完后重启.bat 选 3 可生成 黑名单删除报告.xlsx（含 ID/昵称/创建时间/最后战斗/操作时间/耗时）。


【常见问题】

  Q: 双击没反应 / 提示找不到 Python
  A: 先跑 1_环境检查.bat，它会自动装。

  Q: 游戏里提示 Mod package ... not loaded
  A: 与 Python 无关。看 游戏根目录\game.log 里 mods found 后面那行：
     - compression not supported -> 包要用 stored 压缩（工具包里的包已处理）
     - 目录名不对 -> 必须等于 version.xml 的版本

  Q: 找不到 blacklist_export.json
  A: MOD 没加载或没进车库；game.log 搜 [BLX]

  Q: 删除没反应
  A: 确认 blacklist_delete_go.txt 在游戏根目录；game.log 搜 [BLX-DEL]

  Q: 想取消删除
  A: 启动前删掉 blacklist_delete_go.txt
